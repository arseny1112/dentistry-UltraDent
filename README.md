# 🦷 Стоматология Ультра-Дент

## 📋 Описание проекта
Тестовое задание представляет собой **сайт стоматологической клиники**, разработанный с акцентом на **чистоту вёрстки, адаптивность и визуальную точность (pixel-perfect)**.  
---

## 🚀 Основной функционал
- **Бургер-меню** для мобильных устройств  
- **Секция отзывов** с пагинацией
- **Плавные переходы и hover-анимации карточек**  
- **Адаптивная сетка** без избыточных медиа-запросов  
---

## 💻 Используемые технологии
- **HTML5**
- **SCSS / CSS3**
- **JavaScript (Vanilla JS)**
- Методология **БЭМ (BEM)**
- Подход **Mobile-friendly**

---

## 🧩 Особенности реализации
- Верстка выполнена в соответствии с макетом **1920px (pixel-perfect)**  
- Размеры **1440px и 393px** не детализировались, чтобы:
  - избежать **дублирования и избыточности CSS**;
  - сохранить **структурную чистоту и читаемость кода**;
  - подчеркнуть **приоритет качества и стабильности верстки**.  
- Логика отзывов и пагинации реализована **на чистом JavaScript** без сторонних библиотек.
